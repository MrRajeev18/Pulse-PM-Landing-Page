# PulsePM — Landing Page

> The Real-Time Heartbeat of High-Velocity Product Teams.

PulsePM combines continuous sprint telemetry, automated blocker interception, and verified deliverable checkmarks.

## Project Structure

```
├── index.html        # Main landing page markup
├── styles.css        # Custom styles, ECG animations and responsive styling
├── script.js         # Interactive sprint simulator, tabs, and toggles
└── assets/
    └── logo.png      # Official PulsePM logo
```

## Getting Started

Simply open `index.html` in your web browser:
```bash
open index.html
```

Or run a local static server:
```bash
# Using Python
python3 -m http.server 3000

# Using Node / npx
npx serve .
```
